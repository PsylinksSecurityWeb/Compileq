# Code of Conduct

Compileq is proprietary software from Psylinks Security Private Limited. Public repository visibility is provided for product discovery and authorized evaluation; it does not grant rights to copy, fork, redistribute, or create derivative works.

For authorized discussions, please be respectful, specific, and focused on reproducible product behavior. Do not post personal data, credentials, confidential customer information, or alleged vulnerabilities in public issues or discussions.

For security reports, follow [`SECURITY.md`](./SECURITY.md) and use the private contact route whenever possible.
