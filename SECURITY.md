# Security Policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities, credentials, personal data, or customer code in a public issue. Contact Psylinks Security Private Limited through [psylinksssecurity.com](https://psylinksssecurity.com) with a concise description, reproduction steps, affected version, and impact.

Compileq is a compliance triage tool, not a certification or a replacement for professional legal, privacy, accessibility, or security review.

## Scope

This policy covers the Compileq scanner, MCP server, rule files, report generation, and official-source lookup behavior distributed by Psylinks Security Private Limited.
